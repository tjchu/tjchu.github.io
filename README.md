**Live profile:** [linkedin.com/in/terry-chu-535758a9](https://www.linkedin.com/in/terry-chu-535758a9)

## Site contents

- `index.html` — Homepage, selected career experience, technical skills, and contact links.
- `about.html` — Professional background and areas of experience.
- `css/portfolio.css` — Styles for the current portfolio pages.

The site is built with static HTML and CSS. There is no build step or package installation required.

## Preview locally

From the repository root, start Python's local static file server:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000> in a browser. Stop the server with `Ctrl+C`.

## Publishing

This repository is named for GitHub Pages. If publishing with GitHub Pages, configure the repository's Pages settings to deploy from the `main` branch and the repository root. Changes to the HTML and CSS can then be published without a build command.

## Keeping the profile current

Update career dates, role descriptions, and skills in `index.html` and `about.html` when your professional profile changes. Keep the summary consistent with your current LinkedIn profile.
